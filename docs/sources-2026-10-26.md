## 2026-10-26 변경 내역

- **cha 제거**: 국가유산청 옛 도메인 `cha.go.kr`이 DNS 조회 실패. khs와 같은 `bbzId=newexam` 게시판이고 보존 공고 4건도 모두 khs와 동일 제목이었음 → `crawlers/sites/cha.ts`, run.ts 등록, url.txt 줄 삭제. 결과 데이터(`crawlers/results*.json`, `web/results.json`, source-health, notification-summary)에서도 cha 항목 제거. `data/opportunity-state.json`의 누적 이력 1건은 그대로 둠(이전 결과에서 빠졌으므로 missing 이벤트를 만들지 않음).
- **namuk**: 레지스트리에는 있었으나 `url.txt`에 없었음 → 추가.
- **ep-museum**: `url.txt`가 목록이 아닌 개별 글(`seq=111&page=view`)을 가리키고 있었음 → 등록 config URL로 정정.
- **gjicp**: `gjicp.ggcf.kr`은 경기역사문화유산원 사이트인데 '경기도자미술관'으로 잘못 등록 → 이름 정정 (경기도자미술관은 한국도자재단 소속).
- **종합 사이트 우선 정리**: 개별 사이트 7곳(gcm·jgpm·silhak·gjicp·njp → ggcf, nrich → khs, korea-kr → gojobs)을 등록에서 빼고 `excluded-sources.json`으로 이동. 겹침은 실제 게시판을 대조해 측정했고 수치는 그 파일의 evidence에 있다. khs는 최근 30일(최대 6페이지)을 읽도록 바꾸고 제목의 소속기관명을 기관명으로 기록. 결과 데이터에서도 7곳 항목 제거.
- **사람인 추가 (2026-10-27)**: playMCP 사람인 도구로 workfinder 실행 중 수집. 조건은 저장된 검색 "직업 박물관"(큐레이터·문화재·박물관, 서울·경기). 원 출처 게시판과 겹치는 공고는 `crawlers/secondary-sources.ts`가 자동 제외 — 2026-10-27 공개 검색 60건 기준 5건(국립농업박물관 4, 국립한글박물관 1)이 겹침.
- **신규 20개 소스 추가**: 경기문화재단 본부(ggcf)·백남준아트센터(njp)는 `ggcf.ts` configs, 나머지 18개는 개별 모듈. 검증 기준과 결과는 후보 문서 참고.
