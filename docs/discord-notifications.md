# Discord 알림 연결

Work-Finder는 웹훅 URL을 저장소에 넣지 않고 GitHub Actions의 비밀값 `DISCORD_WEBHOOK_URL`로만 읽습니다.

## 설정

1. Discord에서 알림을 받을 채널의 **채널 편집 → 연동 → 웹후크 → 새 웹후크**를 선택하고 URL을 복사합니다.
2. GitHub 저장소에서 **Settings → Secrets and variables → Actions → New repository secret**을 엽니다.
3. 이름을 `DISCORD_WEBHOOK_URL`, 값은 복사한 URL로 저장합니다.
4. Actions의 `채용공고 크롤링 & 배포` 워크플로를 수동 실행해 시험합니다.

URL이 없으면 배포는 계속되고 알림만 건너뜁니다. URL이 노출되면 Discord에서 기존 웹후크를 삭제하고 새로 만들어 비밀값을 교체합니다.

## 전송 정책

- 오전 6시(KST): 긴급 항목, 신규/변경/종료 수, 소스 상태를 묶은 일일 요약
- 오후 6시(KST): 적합도 70 이상이면서 D-7 이내인 P1 항목과 소스 장애가 있을 때만 긴급 알림
- 최초 실행: 모든 항목을 신규로 오인하지 않도록 기준선만 만들고 알림을 보내지 않음
- Discord 멘션은 비활성화해 제목이나 기관명에 `@everyone`이 포함되어도 호출되지 않음
