# 미래내일 일경험 — 공식 안내 확인 기록

확인일: 2026-09-27. 출처: [경기도일자리재단 사업 상세](https://gjf.or.kr/main/main_biz/search/view.do?main_biz_sn=94), [고용24 청년일경험 프로그램 목록](https://yw.work24.go.kr/d/a/selectWkexPrgmList.do).

- 취지: 미취업 청년이 직무 경험과 경력을 쌓아 취업을 준비하도록 지원하는 사업.
- 경기일자리재단 안내 대상: 15~34세 미취업 청년. 군필자의 연령 확대는 최대 39세로 안내되어 있으므로 개별 공고의 적용 조건 확인 필요.
- 재단의 2026년 운영 범위: 공공기관 특화. 사업 운영시기는 2026년 3월~2027년 2월이며, 이것을 신청기간으로 사용하면 안 된다.
- 공식 신청 안내: [공공특화 청년 모집 링크](https://m.site.naver.com/23Oq0), [청년일경험 포털](https://yw.work24.go.kr/main.do). 재단 연락처: 031-270-9765 / 9767 / 9936.
- 고용24 목록에서 확인할 항목: 참여기업, 직무, 지역, 모집기간, 사전직무교육기간, 일경험기간. 인턴형/프로젝트형 등의 개별 프로그램을 기준으로 접수 마감이 달라진다.
- 주의: ‘일경험’이라는 이름만으로 개인의 지원자격, 정식 근로계약, 학예사 자격 취득에 필요한 경력 인정 여부를 확정할 수 없다. 원문의 참여자격·실제 업무·경력증빙 발급 여부를 확인해야 한다.

Work-Finder는 재단 사업 자체를 ‘사업 안내’로, 고용24의 개별 모집 프로그램을 ‘모집 공고’로 나눈다. 세부 수당이나 모집 인원은 회차별 원문 확인 없이 일반화하지 않았다. 자동 수집 사본은 `data/program-catalog.json`과 `crawlers/experience-results.json`에 저장된다.
